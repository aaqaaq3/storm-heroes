# 🎮 أبطال العاصفة — Storm Heroes

لعبة **باتل رويال** ثلاثية الأبعاد تعمل في المتصفّح مباشرة، أبطالها:
**أسيل • جنان • عبدالله • أسامة**

مبنيّة بمحرّك WebGL 2 مكتوب من الصفر — بلا أي مكتبة خارجية ولا ملفات وسائط:
كل النماذج والأصوات والخرائط تُولَّد إجرائيًّا داخل اللعبة.

> تحتاج متصفّحًا حديثًا يدعم **WebGL 2** — Chrome أو Safari أو Edge بأحدث إصدار.

## 🕹️ التحكّم

| الحركة | القتال | البناء |
|---|---|---|
| `W A S D` تحرّك | `زر الفأرة الأيسر` إطلاق نار | `G` وضع البناء |
| `Shift` جري | `زر الفأرة الأيمن` تصويب دقيق | `Z` جدار |

| `Esc` إيقاف مؤقت | | |

**على الجوال واللوحي:** عصا افتراضية للحركة، وسحب الشاشة للنظر، وأزرار جانبية.

## 🎮 اللعب بيد التحكّم على التلفزيون

اللعبة تدعم يد **PlayStation (DualSense/DualShock)** و**Xbox** وأي يد بمخطّط قياسي.

**كيف؟**
1. وصّل الحاسوب بالتلفزيون بكابل **HDMI** (أو AirPlay).
2. اربط اليد بالبلوتوث: على DualSense اضغط زر **PS** + زر **Create** معًا حتى يومض الضوء، ثم اقرنها من إعدادات البلوتوث في الماك.
3. افتح اللعبة — ستُكتشف اليد تلقائيًّا ويظهر تنبيه.
4. من القائمة: **← →** لاختيار البطل، و**✕** لبدء المباراة.

| الحركة والنظر | القتال | البناء والأدوات |
|---|---|---|
| العصا اليسرى — التحرّك | `R2` إطلاق النار | `■` وضع البناء |
| العصا اليمنى — النظر | `L2` تصويب دقيق | `▲` فتح صندوق / التقاط |
| ضغط العصا اليسرى — جري | `R1` السلاح التالي | `←` `→` نوع البناء |
| `✕` قفز / شراع | `L1` إعادة التعبئة | `↑` درع / علاج |
| `◯` انحناء | ضغط العصا اليمنى — الفأس | `↓` تغيير المادة |
| `Options` إيقاف مؤقت | | `Share` الخريطة |

**تصويب مساعد** مفعّل تلقائيًّا مع اليد لتسهيل اللعب على الأطفال — يمكن إطفاؤه أو ضبط حساسية العصا من الإعدادات.

> **ملاحظة:** اللعبة لا تعمل على جهاز PlayStation نفسه — PS5 لا يحتوي متصفّح إنترنت للمستخدم، ونشر لعبة أصلية عليه يتطلّب رخصة مطوّر من Sony. الحلّ العملي هو توصيل الحاسوب بالتلفزيون واستخدام يد PlayStation كما في الأعلى.

## ⚙️ الإعدادات

من القائمة الرئيسية → «الإعدادات»: حساسية الفأرة، حساسية يد التحكّم، التصويب المساعد،
مستوى الرسومات (منخفض/متوسط/عالٍ)، الأصوات، عكس المحور الرأسي،
عدد اللاعبين (١٠/١٦/٢٤)، وصعوبة الخصوم (سهل/متوسط/صعب).

> إن كانت اللعبة بطيئة على جهازك، اختر **منخفض** — يقلّل دقّة الظلال ويطفئ التوهّج.

## 🧩 بنية المشروع

```
index.html            الصفحة وواجهات القوائم
standalone.html       نسخة بملف واحد (كل شيء مدمج — للمشاركة أو الرفع)
css/style.css         التنسيق (عربي RTL بالكامل)
js/math.js            متجهات، مصفوفات، ضجيج إجرائي
js/geometry.js        مولّد الأشكال ثلاثية الأبعاد
js/shaders.js         مصادر GLSL (سماء، ماء، عاصفة، ظلال، توهّج)
js/gl.js              طبقة WebGL2 والاستنساخ (instancing)
js/renderer.js        العارض: ظلال، توهّج، معالجة لاحقة
js/world.js           توليد الجزيرة والمباني والنباتات
js/characters.js      هيكل الشخصيات وحركاتها
js/weapons.js         الأسلحة والغنائم
js/build.js           نظام البناء الشبكي
js/ai.js              ذكاء الخصوم
js/game.js            منطق اللعبة والفيزياء والعاصفة
js/ui.js              واجهة اللاعب والخرائط والقوائم
js/main.js            التحميل والحلقة الرئيسية
```

## 💡 نصائح للفوز

- اضرب الأشجار والصخور بالفأس لتجمع مواد البناء — الجدار السريع ينقذ حياتك.
- افتح الصناديق الذهبية أوّلًا؛ فيها أفضل الأسلحة والدروع.
- اشرب عبوة الدرع **قبل** بدء الاشتباك لا أثناءه.
- ابنِ منحدرًا لتصعد فوق خصمك — الأعلى يرى أكثر ويصيب أسهل.
- الإصابة في الرأس تضاعف الضرر تقريبًا.
- لا تتأخّر عن الدائرة الآمنة؛ العاصفة تؤلم أكثر في كل مرحلة.
